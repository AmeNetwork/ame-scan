## Ame Scan
Ame Components Scan is a manager for viewing components of various networks. 

### Quick start
**Install dependencies**  

use npm
```
npm i
```
use yarn
```
yarn install
```
**Running locally**
```
npm run start
```
use yarn
```
yarn start
```
